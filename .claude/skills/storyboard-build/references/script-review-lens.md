# Script review lens (optional, upstream only)

A checklist for reading an incoming sales-video script BEFORE it is boarded. It produces notes to
send back to the script's owner. It is never licence to change the script: `storyboard-build`
preserves wording verbatim, and that rule wins.

Use it only when asked to review a script, or when something on this list is conspicuously missing
and worth one line in the board's notes.

**Hook**
- Attention is earned in the first 3-5 seconds. Which kind of hook is it — question, problem,
  curiosity, pattern interrupt, social proof, demonstration? If none, say so.

**Proof — where it sits** (as a share of total runtime)
- Early, around 15-25%: credibility before the big claims
- With the features, around 40-60%: proof next to each key benefit
- Late, around 80-90%: results, just before the ask

**Objections — in the order a buyer raises them**
1. Does it work? → demonstration and proof
2. Will it work for me? → use cases, customer stories
3. Is it too complicated? → show it being simple
4. Is it worth the money? → the value equation
5. What if it doesn't work? → guarantee, risk reversal

**Call to action**
- At least two: one around the midpoint, one at the end
- Specific beats generic ("Start free trial", not "Learn more")
- Remove friction where it is true ("no credit card required")
- Urgency only when it is real — no fake timers, no invented scarcity

**Copy**
- Benefits before features; "you" language; one idea per beat
- No wall of text for any single beat

**Per beat, be able to say** (useful when writing a row's `brief`, even when the copy is fixed)
- Narrative purpose — why this beat exists
- Viewer psychology — what they feel or doubt here, and which objection is being answered
- Sales element — proof, benefit, offer, risk reversal, or CTA

---
Adapted from `vsl-storyboard-writer` in ncklrs/startup-os-skills (MIT per its README). Its fixed
act timings (a 90s arc, a 300s six-act VSL) are not adopted: the board derives structure from the
script's own section headers, at whatever length the script is.
